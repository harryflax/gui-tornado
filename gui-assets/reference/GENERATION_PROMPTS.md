# Art direction and regeneration prompts

These are the prompts used to generate the finished PNGs. Generation requested 1024 × 1024, but the tool delivered 1254 × 1254; the manifest uses the actual delivered dimensions. Do not replace existing art without re-measuring coordinates and updating the manifest, offline preview data, Luau adapter and hashes.

Use the viral-game references from upload `59b573c` for style, and the older upload `8b81e70` for screen features. Source reference screenshots are not runtime assets.

## Navigation spacing revision

The first navigation sheet placed some icons too close for rectangular sprite extraction. The delivered revision preserves the designs but reduces each icon's size and adds large transparent gutters. Sixteen independently measured 240 × 240 rectangles are stored in manifest.json. Do not substitute an assumed equal grid.
