## User's core loop

Build a base with friends during short rounds → survive a tornado → collect storm loot → bring loot to the base → earn cash per second.

The art pack does not change the game's round lengths, economy, inventory, monetization, pet system, or networking. No timing or balancing values from the abandoned web prototype are part of this deliverable.
